# Multiple copies of labels 

Currently, there is the possibility to print labels using a PDF print. I select spools I want to print and it will compose the labels into a PDF file which is used to print them.

Now I need a change. When I select spools to print, after clicking the button "Print labels", I want to select the number of copies of the stickers. The idea is that if I select 3 copies of selected 4 spools, it will produce 12 labels (likely on a single A4 page).

* User cannot select a different number of copies for each spool.
* All spools will get the specified number of labels.
* Labels of a same spool will be grouped.
* The design of the label isn't a subject of this change.
