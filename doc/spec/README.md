# System Specification

This directory describes the Filament application as it currently exists. It is the current-state reference for users, contributors, and operators; completed change requests provide the detailed historical record.

## Contents

- [Application overview](application-overview.md): purpose, scope, and user-visible capabilities.
- [Domain model and rules](domain-rules.md): inventory concepts, identifiers, weights, lifecycle, history, and filtering.
- [Interfaces](interfaces.md): web routes, HTTP API, labels, real-time notifications, and operational endpoints.
- [Architecture](architecture.md): implementation boundaries, data ownership, deployment topology, and consistency behavior.
- [Operations](operations.md): supported Podman Quadlet installation, updates, administration, and recovery.

## Change Requests

Completed requests may be linked here only through their final paths under [`doc/done/`](../done/). Never link a request here through `doc/todo/`, because completed requests are archived.
