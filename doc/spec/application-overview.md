# Application Overview

Filament is a privately hosted application for individuals and small teams to manage filament storage for 3D-print farms.

The application tracks filament types and individual spools, including spool weights, remaining material, usage history, short human-friendly identifiers, printable labels, and stock overviews. It is designed for approximately 50-150 filament types, 50-300 spools, and up to five concurrent LAN users.

Authentication and authorization are currently out of scope.

Detailed requirements and expected use cases are maintained in [`.opencode/opencode-instructions.md`](../../.opencode/opencode-instructions.md).
